
ElectraStock Pro Notes

UI / UX

* Increase font size throughout the application. Still feels too small on desktop.
* Improve spacing and reduce unnecessary white space.
* Dashboard needs a more premium/professional feel. Data is good but UI looks plain.
* Make all pages desktop-first. Mouse usage should be optional, not mandatory.
* Keep layouts consistent across all modules.


POS Billing

* Billing should be 100% keyboard navigable.
* Fix arrow navigation everywhere.
* Right → next field.
* Left → previous field.
* Up/Down should increase/decrease values in numeric fields instead of moving focus.
* Enter should confirm wherever applicable.
* ESC should close drawers/popups.
* F-keys should always work consistently.


Billing Workflow

Current flow needs to feel more natural.

Desired flow:

Search Product

↓

Add/Edit Products

↓

(Optional) Select Customer

↓

Select Payment Mode

↓

Complete Bill

Customer selection should always be optional.

Default customer = Walk-in Customer.
